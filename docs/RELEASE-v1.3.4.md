# 牛马鼓励器 v1.3.4

加油打工人，搭子陪你倒数下班。

- 小红书 H5 支持午休和下班倒计时、收入估算、今日购买力、工位搭子、待办和久坐提醒。
- 桌面版新增置顶、迷你悬浮窗和菜单栏／托盘恢复，自定义搭子与商品编辑可以直接使用。
- macOS 分为 Apple Silicon 和 Intel 两个包。Windows 提供 64 位免安装包，解压后运行 `Niuma.exe`。

Apple Silicon 版已运行验证。Intel Mac 和 Windows 10 版已校验打包内容与架构，待对应设备实测。Mac 版未做 Apple 公证，Windows 版未做发行签名。各附件的 SHA-256 见 `SHA256SUMS.txt`。
